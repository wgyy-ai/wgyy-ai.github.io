# BioVFM-21M

## Dataset Information

BioVFM-21M is a curated large biomedical image corpus introduced for benchmarking and scaling self-supervised biomedical vision foundation models. The GitHub README states that it contains 21 million biomedical images collected from 61 publicly available data sources.

The maintainers explicitly note that they do not host or redistribute raw source data. Instead, they provide a complete data list with filenames and raw paths, while requiring users to download source data from the official dataset providers under the original licenses.
