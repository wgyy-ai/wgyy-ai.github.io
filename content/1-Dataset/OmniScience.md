# OmniScience

## Dataset Information

OmniScience is a large-scale scientific multimodal dataset for image understanding. The public README states that it comprises 1.5 million high-quality image-text pairs and more than 5 million sub-figures, with total compressed size exceeding 700 GB.

Although OmniScience is not restricted to medicine, it covers scientific imagery broadly and is relevant for biomedical figure understanding and multimodal pretraining in scientific domains.
