# PreCT-160K

## Dataset Information

PreCT-160K is a large-scale 3D medical image pretraining dataset introduced together with the VoCo framework for geometric-context-based medical pretraining. The associated paper explicitly describes PreCT-160K as the largest medical pretraining dataset in that work.

The Hugging Face repository is linked from the official project page and reports Apache-2.0 licensing for the repository wrapper, a total hosted size of 5.63 TB, and usage alongside the paper "Large-Scale 3D Medical Image Pre-training with Geometric Context Priors."
