# open-pmc-18m

## Dataset Information

open-pmc-18m is a large biomedical image-text dataset released as a WebDataset on Hugging Face by the Vector Institute. The public viewer reports roughly 16.1 million training rows and shows each example as a JPEG image paired with JSON metadata containing a caption.

The dataset is built from open-access PMC content and is intended for large-scale biomedical vision-language pretraining. Public metadata lists MIT licensing and arXiv links including 2506.02738.
